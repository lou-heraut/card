# CARD catalogue

Generated by `scripts/generate_catalog.py`, do not edit by hand. The corpus count is in the README. [Version française](CARDS.fr.md).

**Reading a name.** Identifiers are systematic, and read left to right: quantity (`Q` discharge, `R` precipitation, `T` temperature, `ETP` evapotranspiration), time step (`A` year, `M` month, `S` season, `J` day), order statistic (`N` minimum, `D` median, `X` maximum, nothing = mean), season. A prefix transforms the output (`delta-` change between two periods, `mean-`/`median-` inter-annual, `rp-` return period), a suffix qualifies it (`-10` ten-year return period, `_summer`, `_H` projection horizon). So `QJXA` reads discharge, daily, maximum, annual. Full grammar: [NOMENCLATURE.md](dev/NOMENCLATURE.md).

Filed by **domain / phenomenon**. Each card runs through `card.extract(data, cards=[...])`; *inputs* are the columns `data` must contain (see `rename=`). Details of one card: `card.info("name")`.
